# USK Logistics (usklogistics.kz)

Доставка и выкуп товаров из США / Европы / Китая в Казахстан. Статичный сайт (HTML/CSS/JS) + PHP/MySQL API на Plesk (Hoster.kz). Владелец не технарь - общаемся по-русски, коротко и простым языком.

ВАЖНО: этот файл публичный (деплоится вместе с сайтом). Никаких паролей, ключей, токенов и URL вебхуков сюда не писать.

## Деплой и git
- Репозиторий: `tainaro25/usk-logistics-site`, ветка `main`. Пуш в `main` -> Plesk сам подтягивает через вебхук. Если на живом сайте старая версия - проверить Git-раздел в Plesk (кнопка Pull Updates).
- Перед работой: `git pull`. После: коммит + пуш. Не править одни файлы с двух компьютеров одновременно.
- Локально в репозитории нужна своя git-личность (`git config user.name` / `user.email` без `--global`) и свой SSH deploy key с правом записи.
- Коммитить конкретные файлы, не `git add -A` вслепую: в папке бывают локальные служебные файлы (`serve.ps1`, `.claude/`, старая `site/`, csv) - они исключены через `.git/info/exclude` и на сервер попадать не должны.

## Секреты
- Настоящие `db-config.php`, `telegram-config.php`, `email-config.php` НИКОГДА не в git и не в рабочей папке. В репозитории только `*.example.php`. Реальные файлы владелец кладёт прямо в Plesk File Manager.

## Правила работы
- Новые фичи делаем только на RU-страницах. `en/` и `admin.html` не трогаем, пока владелец явно не попросит. Исключение: просьбы что-то убрать "со всего сайта" - тогда убираем и в en/.
- Страницы личного кабинета (`account-dashboard.html`) двуязычные (RU/KK через `assets/i18n.js`): новые тексты добавлять в оба блока `ru` и `kk`.
- Кэш-бастинг: при изменении `assets/style.css` или `assets/i18n.js` поднимать `?v=N` во ВСЕХ HTML, которые их подключают (сейчас style v=59, i18n v=27, script v=22). Пользователи иначе видят старый файл.
- Новая страница = добавить в шапку, футер и `sitemap.xml`.
- Фото: не брать чужие фото (Apple, магазины, агентства) - нет прав. Делаем свои SVG-иллюстрации/градиентные обложки.
- Новости: отдельная страница на каждую в `news/`, список в `news.html`, в тексте - CTA на форму заявки. SEO: уникальные title/description, один h1, JSON-LD Article.
- Нумерация заказов `№N` у клиента считается на лету (порядок по created_at у каждого user_id), не хранится в БД: `api/me.php` и `api/admin-orders.php`.

## Вёрстка и мобильная версия
- Проверять на ширине 375px. На `html, body` стоит `overflow-x: hidden` как страховка, но реально чинить причину.
- Дети CSS Grid в мобильной сетке должны иметь `min-width: 0`, иначе колонка не сжимается ниже содержимого.
- Мобильная шапка: логотип + кнопка заявки + гамбургер. Язык и тема - внутри меню (`.nav-mobile-controls`). Переключатель темы ищется по классу `.theme-toggle` (их два в DOM).
- Тёмная тема: цвета только через CSS-переменные; жёстко заданные цвета (например `#333`) ломают тёмную тему.

## Локальный просмотр
- Скрипт `serve.ps1` (порт 8890, отдаёт корень репозитория) + `.claude/launch.json`; в git их нет, при необходимости воссоздать. PHP локально нет: запросы к `api/*.php` не работают, для проверки кабинета подменять `fetch`.
- Ошибка "Dev servers are not available for this session" - временный сбой, просто повторить запуск.
